AgentGuard AI — Compounding Errors in Agentic AI

HOW TO RUN
1. Extract the ZIP file if you downloaded it as a ZIP.
2. Open the agentguard_ai folder.
3. Double-click index.html.
4. It opens in your default browser. No server, internet, API key, or installation is required.

DEMO
- Select Without checks and click Run agent to see the incorrect date propagate.
- Click Reset demo, select With checkpoints, then Run agent.
- When payment pauses, click Approve payment to finish the simulated workflow.
- Adjust the three sliders in Success-rate calculator.
- Read Audit log for the record of each action.

IMPORTANT
This is a front-end simulation, not a live AI system. It does not book travel, send messages, or charge money.
The calculator states its assumptions in the interface.
